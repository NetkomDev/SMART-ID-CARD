# Desain PWA dan akses sekolah — 28 September 2026

## Cakupan

Empat portal pengguna: Orang Tua, Bank Sampah, Ekstrakurikuler, Perpustakaan. LED Gateway dan Command Center tetap merupakan layar/perangkat operasional, bukan portal manusia yang mendapat login QR sekolah. Admin Web tetap memiliki autentikasi akun tersendiri.

Tema bersama di `apps/shared/portal-theme.css`: navy #102f43, teal #0c5260, latar #f2f6f8, kartu putih, tipografi sistem, tombol minimal 48px, fokus keyboard terlihat, dan dukungan reduced motion. Seluruh portal memakai komponen instruksi akses yang sama, bidang input berlabel, tata letak responsif, dan warna manifest yang konsisten. Cache service worker dinaikkan versinya; API maupun token QR tidak masuk cache service worker.

## Pemetaan blueprint

- Bagian 28–30: Orang Tua melihat anak yang terhubung, dapat memilih anak, melihat timeline kehadiran/perpustakaan/sampah/ekskul, menautkan anak, dan menyimpan aplikasi ke layar utama. Waktu timeline mengikuti zona waktu sekolah. Tombol Beranda, Tambah anak, Akses saya, dan Keluar memiliki aksi.
- Bagian 31–34: Bank Sampah menggunakan akses kelas → scan QR siswa → identifikasi siswa → input setoran → simpan → konfirmasi. Input kilogram maupun kantong yang diketik dicatat MANUAL; pemilihan satuan tidak membuktikan timbangan terhubung. Konversi kantong yang sudah ada tetap 0,5 kg/kantong.
- Ekstrakurikuler mempertahankan daftar kegiatan, pemilihan sesi, presensi QR dan konfirmasi pendaftaran anggota; ditambah tombol keluar yang terlihat.
- Perpustakaan mempertahankan scan QR/UID, hasil identifikasi, antrean lokal dan sinkronisasi. Tidak mengklaim NISN dapat dibaca endpoint yang sebenarnya menerima QR/UID.

## Batas akses

URL dasar tanpa QR atau sesi yang sah hanya menampilkan petunjuk akses; tidak mengambil data tenant. QR portal ditukar melalui server, rahasianya dibuang dari URL, dan browser menyimpan sesi yang dapat diperbarui. Aplikasi terpasang dapat dibuka kembali dengan sesi tersebut, sesuai blueprint. Server memeriksa peran, tenant, masa berlaku dan pencabutan akses. QR kartu siswa bukan token login portal.

Migrasi `202609280025_school_owned_portals.sql` membatasi `can_manage_portal_access` serta pemeriksaan aktor dalam `provision_portal_access` pada SCHOOL_ADMIN aktif milik sekolah tujuan. Akun platform, akun portal dan administrator sekolah lain tidak dapat menerbitkan QR. Syarat diperiksa sebelum membuat identitas Auth dan di transaksi provisioning. Migrasi ini belum diterapkan ke Supabase remote; CLI terakhir ditolak dengan HTTP 403. Terapkan setelah migrasi sebelumnya menggunakan akun pengelola proyek yang berwenang.

Dashboard Super Admin dipisahkan dari dashboard sekolah: navigasi hanya platform, tanpa pemilih untuk masuk operasional tenant. Pemilihan sekolah untuk produksi kartu tetap berada dalam modul produksi. URL operasional sekolah pada sesi Super Admin dialihkan ke `/platform`. Admin Sekolah tidak dapat membuka modul produksi; API menolak daftar/detail batch dan aksi produksi/cetak bagi akun tanpa otoritas platform. Mencetak kartu berbeda dari mencetak QR akses portal yang menjadi tugas Admin Sekolah.
