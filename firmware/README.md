# AKSIS Firmware Subsystem (`firmware/`)

## Overview
Intermediate blueprint organizing micro-controller firmware source code, hardware connection diagrams, and low-level card station communication protocols for AKSIS peripheral devices.

## Subdirectories & Boundaries
- [esp32-pn532-card-station](./esp32-pn532-card-station/README.md): Microcontroller firmware for the ESP32 + PN532 smart card encoder station.
